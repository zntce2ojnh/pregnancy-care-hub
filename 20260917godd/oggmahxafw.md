# “消炎止疼药”不是“消炎药”，颈肩腰腿痛可不能吃错药

作为一名专业治疗颈肩腰腿痛的医生，却为了劝说患者合理服用消炎止疼药而愁秃了头。您看，又一位患者走进了小祝医生的诊室。

今天，小祝医生就给大家科普一下颈肩腰腿疼为什么需要合理地吃“消炎止疼药”。

首先说明一下什么是炎症

**炎症的科学定义是“具有血管系统的机体对损伤因子的防御反应”**。

从这个定义出发，我们常见的腰腿疼、肩周炎、颈椎痛、关节痛是因为过度或不恰当的使用而造成的，都是炎症，我们称之为无菌性炎症。

用一块整洁的草坪打比方。一旦草坪被人过度踩踏，就不长草了，这类炎症的损伤因子就是不正常的或过度的劳损。要修复这块草坪，首先要避免再踩踏（休息）和给被踩踏的地方松土，消除不利于长草的局部因素（消炎止疼药）。

在门诊，经常有患者说：“我上次脖子疼你给我开这个药，这次脚后跟疼你也给我开这个药，靠不靠谱啊？”其实，**这类无菌性炎症的发病机理类似，治疗原则也基本相同**，这种治疗是靠谱的。

而**消炎药对应的是细菌性炎症**，比如阑尾炎、肺炎、体表长个大脓包等，这类炎症的损伤因子是细菌（或其他病原体）入侵人体。

如果再用草坪打比方，那就是长杂草了，此时应该用除草剂（抗生素）精准清除杂草，而不能杀死正常的草坪。

**颈肩腰腿痛患者体内并没有细菌造成的感染**（杂草），所以此时用消炎药，不仅不管用，还会让消炎药杀伤人体内的正常细菌（菌群），造成菌群失调，伤害健康。

**那消炎止疼药伤胃的说法是怎么来的呢？**

这个要从消炎止疼药的作用机理说起。

消炎止疼药的学术名称叫“非甾（zāi）体抗炎药”。通俗地说，它的消炎止疼原理，是通过抑制一种叫环氧酶（COX）的酶类起作用，环氧酶呢在人体内分为1号（COX-1）和2号（COX-2）。1号是“好的”，主要分布在胃、肾等部位；2号是“坏的”，能产生一些有害因子，让人感觉到疼痛。

理想的情况下，只抑制炎症反应区域的酶，而不抑制胃和肾上的“好”酶。国内外的药物科学家一直在坚持不懈地为减少消炎止疼药对胃和肾等区域的损伤而不断研发新药。非甾体消炎止疼药的研发应用历史有将近100 年了，国内外都有非常严格的药物不良反应监测上报系统，**实际上它的心脑血管和胃肠道不良反应发生率都在一个很低的水平**，伤胃、伤肾的病例大多发生在大剂量服药、长期连续服药、多种消炎止疼叠加服药等情况下。

**最后，有几点小建议要告诉大家**

1. 掌握消炎药和消炎止疼药的区别，对症用药。

2. 消除对消炎止疼药的恐惧心理，论及“伤胃”的话，大多数药物都不及烟、酒和辛辣。

3. 遵循医生和药师的建议，合理用药，避免长期、大剂量、叠加用药。

4. 避免酒后服药。
