# 精准监督再发力 ——温州市人民医院启动制止餐饮浪费专项监督行动

> 更新时间：2026-09-17 (UTC+8)

**厉行节约 反对浪费**

杜 / 绝 / 舌 / 尖 / 上 / 的 / 浪 / 费

为深入贯彻落实习近平总书记关于节约粮食、制止餐饮浪费行为的重要指示精神，狠刹奢侈浪费歪风，推动全院形成勤俭节约的良好风尚，温州市人民医院党委统一部署，近日成立以党委副书记胡建锋为组长的督查专班，正式启动制止餐饮浪费行为专项监督行动。

专项行动开展以来，院领导胡建锋、李家仁、朱迎阳根据条块部署落实两个责任。纪检监察室联合党政办、内审室、总务科对主体责任落实、职能部门履职、制度规定执行等方面开展重点督查。

9月24日、25日专项督查中发现，医院已建立了制止餐饮浪费专项工作领导小组，明确了分管领导及责任部门，已开展制止浪费的相关学习、宣传活动，但文件、制度、台账的形成、传达、存档工作还需加强。审计专业人员还对公务接待、报销明细账目等资料进行了专项检查。对检查中发现的问题，督查成员已在现场对相关科室工作人员提出了完善要求。

在就餐时段前后，李家仁副院长带队分别于娄桥、信河院区食堂开展了专项督查。检查组成员深入食堂菜品加工操作间，对每一个环节进行了观察和询问。检查中了解到，食堂工作人员能够根据现场就餐人数、用餐量，实时把握菜品加工用量和节奏，较好地避免了加工环节的浪费。在取餐窗口，配餐员使用的配餐工具在尺寸上已有所调整，使配餐量更为精准；饭、汤等窗口，也都设置了多、中、少三种规格的饭、汤供选择。

食堂电子屏、墙面、配餐处等的“光盘行动”标语、宣传画，食堂刷卡及配餐窗口都已放置提示标语，提醒职工自觉抵制“舌尖上的浪费”，节约粮食、制止浪费的宣传氛围十分浓厚。

检查人员还对现场就餐职工的用餐情况进行了巡视，在厨余垃圾倾倒处观察，发现职工们总体都能响应“光盘行动”号召。食堂也配备了劝导员，对部分有较多剩菜、饭的职工做劝导。

副院长李家仁对检查情况做了总结，并提出了改进餐饮用具、劝导员需有鲜明标志等的建议。

下一步，医院还将通过突击检查、交叉互查、专项检查等方式，严明纪律要求，继续加强对相关职能部门履职情况的监督检查，督促各部门切实加强公务活动用餐管理；加强餐饮生产、收储、加工等环节的管理，有效减少损失浪费；推进单位食堂节约用餐，发挥监察网格的监督、宣传作用，引导职工节约用餐；加大反对食品浪费的宣传报道力度，营造浪费可耻、节约为荣的氛围；探索行之有效的措施办法，建立长效机制，推动专项监督取得良好成效。
