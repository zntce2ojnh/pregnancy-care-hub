# 习惯性流产病因有哪些

> 更新时间：2026-09-11 (UTC+8)

孕育新生命是夫妻间一起期盼的，也是双方爱情的结晶，幸福的源泉。很多女性都希望拥有属于自己的宝宝，但是习惯性流产却把这份希望给打破。可为什么有些人会出现习惯性流产呢。如果想进一步知道造成习惯性流产的原因，我们来一起了解下。

1、黄体功能不全

在卵巢破裂排卵之后，会形成黄体，这种黄体可以分泌孕激素和雌激素，如果是黄体功能不全，就会导致雌孕激素不足，不能满足孕育的需要，导致患者流产。

2、子宫发育异常

先天性的子宫畸形 如鞍状子宫、子宫过小，双角子宫，以及后天的子宫疾病如子宫肌瘤、宫腔粘连等也都会导致孕妇流产。

3、遗传因素

如果是近亲结婚，那么夫妻其中任一方染色体出现异常，都可能引起胚胎的异常，导致胚胎不能存活而流产，还有可能出现有畸胎，胎儿发育迟缓等等情况，都是导致流产的原因。

4. 子宫颈内部松弛

由于手术损伤或先天性发育异常，颈内口会扩张。怀孕中后期，羊水会增多。胎儿会慢慢长大，这会增加子宫腔的压力。一旦胎囊从宫颈口通过，如果口部突出，就会导致宫颈管缩短、扩张。一旦压力增大到一定程度，胎儿就会被排出而流产。

5、母子血型不合

如果母亲和胎儿的血型不相容，胎儿从父亲那里获得抗原，进入母亲体内后会产生抗体。这些抗体通过胎盘进入胎儿的血液循环，产生免疫作用，严重时可导致胎儿死亡。这是晚期流产。

6. 分娩太晚

在如此巨大的社会压力下，很多夫妻不愿意过早要孩子，总想奋斗几年才能生孩子。然而，当她们想要孩子时，却无法怀孕，成为习惯性流产。随着年龄的增长和现代社会的开放，物质环境也受到很大的影响。例如服用过多的避孕药、过多的人流等都会导致习惯性流产。
