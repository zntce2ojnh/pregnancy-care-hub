# 实验室再添国际前沿设备：「时差培养箱」无干扰培育、连续胚胎监测助好孕

> 更新时间：2026-09-16 (UTC+8)

对于进行试管助孕的家庭来说，心里最在乎的事情莫过于最终能不能顺利抱到宝宝了，而与之密切相关，甚至起着决定性作用的便是胚胎的质量。虽然胚胎的质量在很大程度上由卵子和精子的质量决定，但在实验室中的胚胎培养和最终的胚胎评级与移植决策（选择哪一枚胚胎进行移植），也同样影响着助孕结局。

近日，深圳恒生医院生殖医学科引进了目前国际前沿设备**胚胎连续观察培养系统（Time-lapse Embryo Monitoring System），也就是俗称的“时差培养箱”（型号：GENEA Geri）**。那么时差培养箱到底先进在哪里，和传统的培养箱有什么区别呢？

▲ Time Lapse 培养系统

**一站式、无干扰培养**

Time Lapse /

培养箱是胚胎居住的第一个家，要保证稳定的温度、湿度、二氧化碳浓度及氧浓度，为胚胎发育提供最佳的环境。

传统培养箱在培养过程中，为了观察发育情况，胚胎学家需要定期开箱、拿出、观察、再放入，过程中难以保证胚胎培养环境的稳定。

▲ 传统培养箱需要定时开盖取出胚胎进行观察

而时差培养箱的每个“房间”都单独设有一套自动对焦成像系统，可以无间断自动监测胚胎的发育过程，并且每隔10分钟生成一次影像，记录胚胎发育过程中的各种参数信息。**这样一来，胚胎从放入培养箱，到取出进行下一步操作之前（移植/冷冻/丢弃等），都在一个相对稳定的环境中发育。**

▲ 通过时差培养箱的屏幕即可实现胚胎观察

**更精准、客观的连续式观察**

Time Lapse /

除了给胚胎提供稳定的发育环境，时差培养箱对胚胎的连续性观察还能为胚胎学家提供比人工观察更客观和丰富的胚胎发育信息，帮助判断胚胎的发育情况和评估潜力，有利于作出最优的移植决策。

▲ 使用传统培养箱的胚胎观察，以日为单位，观察关键发育节点

使用传统培养箱的情况下，胚胎学家会在每天定时拿出胚胎进行观察。胚胎学家在Day1（第一天），也就是取卵的第二天进行原核观察，若出现2个原核，则判定为正常受精。Day2、Day3（第二、三天）观察胚胎分裂的细胞数和碎片率，若选择养囊，则在Day5、6（第五、六天）进行囊胚发育的观察。由于需要尽可能降低对胚胎的影响，所以一般情况下不会对胚胎作次数更多的观察，仅在必要节点进行观察。**这样的观察模式可以对胚胎作出大致的评估，却不能判断关键节点以外的发育过程是否正常，一些潜在的发育问题难以被发现，比如，原核过早出现或消失、细胞直分裂（一分为三）、逆分裂等。**

▲大量研究显示，胚胎并不是匀速发育的，每个发育阶段持续的时间不尽相同，因此连续性的胚胎观察能够比每日定期观察获得更丰富的数据

时差培养箱的连续性观察影像可以为胚胎学家提供更丰富、直观的参考资料。也就是说，胚胎学家可以清楚地看到胚胎什么时间发育到什么阶段，**根据胚胎发育的速度和状态可以排除一些潜在风险，进行更为准确的评级，最终挑选出发育潜能最佳的胚胎进行移植。**

**AI评级系统与机器学习**

Time Lapse /

另外，时差培养箱不仅是一个硬件先进的培养箱，它还是一套拥有先进软件的系统。时差培养箱可以通过对临床数据的回顾性学习和分析，形成适合本实验室的个性化人工智能评级系统，根据胚胎培养收集的丰富信息，对每枚胚胎的发育潜能进行评估、打分及自动排序、为胚胎的挑选及后续的抉择（冷冻、移植、养囊等）提供更加准确、客观的数据。

也就是说，时差培养箱通过集成和运用成千上万个胚胎及其移植结局的数据，给眼前的胚胎进行评估和预测，让胚胎评级和移植决策不再局限于胚胎学家的个人经验当中。

时差培养箱为胚胎创造独立、无干扰的培养环境，提供稳定的培养条件，为胚胎发育保驾护航，并以智能化系统助力精准移植决策。目前，时差培养箱已在恒生医院生殖医学科展开使用，希望为广大的助孕家庭提供更理想的妊娠结局。
